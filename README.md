# 💱 Currency Converter

A simple **Currency Converter Web App** that allows users to convert money from one currency to another using real-time exchange rates. The project is built using **HTML, CSS, and JavaScript**, making it a great beginner-friendly project for learning API integration and DOM manipulation.

## 📄 Files Description

### 1️⃣ index.html

This file contains the **main structure of the web application**.
It includes:

* Input field for entering the amount
* Dropdowns for selecting currencies
* Convert button
* Section to display the converted amount

---

### 2️⃣ style1.css

This file is responsible for the **styling and layout** of the application.

It includes:

* Page layout and alignment
* Styling for input fields and buttons
* Responsive design
* Colors, fonts, and spacing

---

### 3️⃣ convertor.js

This file handles the **logic of the currency converter**.

Functions included:

* Fetching real-time exchange rates from an API
* Calculating the converted amount
* Updating the result dynamically on the page
* Handling user input and button actions
